# Pomoika для Windows

[Скачать последнюю версию](https://github.com/Relfor2/Pomoika-Releases/releases/latest)

1. Скачай `Pomoika-windows-x64.zip` из раздела Assets.
2. Распакуй архив целиком. Папка `_internal` должна лежать рядом с `Pomoika.exe`.
3. Запусти `Pomoika.exe`.

Начиная с версии 1.5.4, обновления можно проверять в настройках на вкладке **Общие**. Нажми **Проверить обновления**, затем подтверди установку, если найдена новая версия.

При ручном переходе со старой версии закрой прицел через меню в трее. Распакуй новую сборку в отдельную папку и перенеси туда `crosshair_configs`, если профили хранятся рядом со старым EXE.
